## Cloudflare – zakres odpowiedzialności

W tym środowisku Cloudflare odpowiada za:
- publiczny DNS i proxy HTTPS,
- terminację TLS i ochronę origin,
- dostęp Zero Trust (Access),
- wystawianie usług przez Cloudflare Tunnel.
